# Clínica virtual — Programación 2

Proyecto final separado en dos aplicaciones:

- **backend/**: API Express + TypeScript + MySQL/MariaDB.
- **frontend/**: Angular 21 + Angular Material.

## Empezar

1. Seguir [la instalación del backend](backend/README.md): configurar `.env`, crear una base vacía y cargar los datos de demostración.
2. Seguir [la instalación del frontend](frontend/README.md).
3. Abrir `backend/Backend.code-workspace` y `frontend/Frontend.code-workspace` en ventanas separadas de Visual Studio Code.

Las contraseñas de demostración están en [LEEME-PRIMERO.md](LEEME-PRIMERO.md). Las instrucciones «En esta computadora» y el script `Iniciar-base-local.ps1` describen únicamente la instalación original; para otra computadora hay que seguir los README de cada aplicación.
